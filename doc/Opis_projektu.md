# 📝 Opis Projektu: Student To-Do List

## 🎯 Cel
Projekt dotyczy stworzenia prostej i intuicyjnej aplikacji typu **"To-Do List"**, dedykowanej studentom. Celem jest pomoc w planowaniu nauki bez zbędnego komplikowania procesu.

## 🧩 Rozwiązywany problem
Aplikacja adresuje konkretne problemy studentów:
* Zapominanie o terminach zadań domowych i kolokwiach.
* Brak struktury w codziennym planowaniu nauki.
* Przeładowanie informacjami w istniejących, skomplikowanych narzędziach.

## 👥 Grupa docelowa
Głównymi odbiorcami są **studenci (18-25 lat)**, którzy szukają minimalistycznego narzędzia do szybkiej organizacji dnia, bez konieczności konfiguracji skomplikowanych kalendarzy.

## 🚀 Główne funkcje
1.  **Szybkie dodawanie zadań** – wprowadzanie nazwy i daty.
2.  **Odznaczanie gotowych** – satysfakcjonujące "odhaczanie" zrobionych rzeczy.
3.  **Lista priorytetów** – wyróżnianie zadań "Pilnych" kolorem.
